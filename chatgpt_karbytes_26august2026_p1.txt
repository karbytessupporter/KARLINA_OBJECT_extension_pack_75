# Limitations

The main weaknesses are architectural rather than conceptual.

The page is almost impossible to navigate conventionally:

* More than 100,000 words occupy one narrow column.

* There is no internal table of contents.

* Hundreds of visible headings are not semantic headings.

* The opening image has no alternative text.

* Long raw URLs repeatedly interrupt prose.

* Many tables require preformatted scrolling.

* The same media and concepts are described multiple times at different analytical depths.

* The reader cannot easily distinguish firsthand analysis from later summaries without carefully tracking which exchange produced which claim.

Its preservation strategy also remains dependent on many external components:

* WordPress rendering.

* Raw GitHub files.

* Wayback Machine captures.

* Linked ontology pages.

* Media codecs.

* Future browser behavior.

The page records many technical measurements, but most are claims preserved from earlier analysis sessions rather than data accompanied by reproducible scripts. Differences such as the 117-versus-106-Hz estimate for the same short voice clip show why those numbers should be treated as contextual approximations rather than absolute traits.

Finally, the page’s scale partially defeats its own desire for compression and minimalism. It is highly information-rich, but not necessarily information-efficient. Yet the redundancy also performs an archival function: later readers can reconstruct the same event through several independently worded descriptions.
